## rled - сервис экранов

Задачи сервиса:

- \[ \] Реализовывать [REST API](https://ru.wikipedia.org/wiki/REST) для взаимодействия с клиентами
- \[ \] API должно работать со всеми экранами одинаково и всеобъемлюще
- \[ \] Обнаруживать и работать с поддерживаемыми Bluetooth-экранами
- \[x\] Реализовывать виртуальный экран
- \[x\] Симулировать реальный экран и отображать его в браузере, что было бы удобно для отладки
