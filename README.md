# Курс по языку программирования Rust

## Строение репозитория

* Корень удобно открыть из [obsidian](https://obsidian.md/)
* `assignments` задания
* `crates` [рабочее пространство](https://doc.rust-lang.ru/book/ch14-03-cargo-workspaces.html) cargo. Эту директорию нужно открывать в Visual Studio Code или другом редакторе. Из нее же и нужно запускать `cargo`
* `keynotes` - презентации

## Полезные материалы

### Книги и статьи

* [**Экспериментальная версия книги**](https://rust-book.cs.brown.edu/) с вопросами и другими интерактивными элементами. [**The Rust Programming Language Book**](https://doc.rust-lang.org/book/) — официальная книга по Rust, идеальная для начинающих, с подробными объяснениями и примерами. 
* Бумажная [**«Программирование на языке Rust»**](https://dmkpress.com/catalog/computer/programming/978-5-97060-236-2/) — отлично подойдет если уже есть знания С++, материал подается быстрее.
* [**Rust для функциональщиков**](https://www.eyalkalderon.com/blog/rust-for-functional-programmers/) — разбор сложностей Rust с точки зрения функционального программирования.  
* [**Learn Rust With Entirely Too Many Linked Lists**](https://rust-unofficial.github.io/too-many-lists/) — углублённое руководство по Rust через реализацию связных списков.
* [**Some mistakes Rust doesn't catch**](https://fasterthanli.me/articles/some-mistakes-rust-doesnt-catch) — взгляд на языки как на инструменты, сравнение современных языков.

### Практика

* [**Rust Playground**](https://play.rust-lang.org/) — онлайн-редактор для экспериментов с кодом на Rust.  
* [**Rustlings**](https://github.com/rust-lang/rustlings) — 
небольшие упражнения для изучения Rust, которые помогут закрепить теорию на практике.
* [**Compiler explorer**](https://godbolt.org/) — онлайн-дизассемблер.

### Руководства и оформление

* [**Rust API Guidelines**](https://rust-lang.github.io/api-guidelines/) — ключевые рекомендации по созданию идиоматичных и совместимых API на Rust, основанные на опыте разработки стандартной библиотеки и экосистемы.
* [**Conventional Commits**](https://www.conventionalcommits.org/) — стандарт для атомарных коммитов с привязкой к SemVer, которое используется в Rust.
* [**Cargo Book**](https://doc.rust-lang.org/cargo/) — официальное руководство по Cargo, менеджеру пакетов и системе сборки Rust.
